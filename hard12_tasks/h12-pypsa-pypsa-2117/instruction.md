Piecewise marginal cost fails with multi_investment_periods

> [!NOTE]
> The following content was generated by AI.

A piecewise `marginal_cost` curve raises `ValueError: Index data must be 1-dimensional` under `multi_investment_periods=True`.

```python
import pandas as pd
import pypsa

n = pypsa.Network()
n.set_snapshots(pd.MultiIndex.from_product([[2030, 2040], [0, 1]]))
n.investment_periods = [2030, 2040]
n.add("Bus", "b")
n.add("Load", "d", bus="b", p_set=50)
n.add("Generator", "g", bus="b", p_nom=100, marginal_cost={0.0: 0, 0.5: 10, 1.0: 30})
n.optimize(multi_investment_periods=True)  # ValueError: Index data must be 1-dimensional
```

- Same network without `multi_investment_periods` solves.
- Cause: `define_piecewise` passes `Generator-p` with the `(period, timestep)` MultiIndex `snapshot` coordinate to `m.add_piecewise_formulation`. linopy's `_broadcast_points` reads that coordinate as tuples and `expand_dims` fails (`linopy/piecewise.py:1051` on master).
- Fix belongs here: linopy 1.0 drops MultiIndex coordinates (PyPSA/linopy#1041, PyPSA/linopy#1082).
