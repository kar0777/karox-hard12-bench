`primary_energy` GlobalConstraint with `investment_period` raises `KeyError` for per-period storage with emissions

### Issue Description

A `primary_energy` GlobalConstraint that sets `investment_period` raises `KeyError` when a StorageUnit with `state_of_charge_initial_per_period = True`, or a Store with `e_initial_per_period = True`, has a carrier with emissions.

`define_primary_energy_limit` cuts the state of charge to the stated period's snapshots, `period_sns` (`optimization/global_constraints.py:371`). It then selects `period_last_sns`, the last snapshot of every period in the horizon (`:469` for StorageUnit, `:521` for Store). Those snapshots of the other periods are not in `period_sns`, so the selection fails.

The same network without `investment_period` on the constraint solves. Each period's closing level should enter the row only for the period the constraint states.

### Reproducible Example

Run with `uv run --script mre.py`.

```python
# /// script
# dependencies = ["pypsa==1.4.0", "highspy"]
# ///
import pandas as pd

import pypsa

n = pypsa.Network()
n.set_snapshots(pd.MultiIndex.from_product([[2030, 2040], [0, 1]]))
n.investment_periods = [2030, 2040]
n.add("Carrier", "gas", co2_emissions=0.2)
n.add("Bus", "b")
n.add("Load", "d", bus="b", p_set=10)
n.add("Generator", "g", bus="b", p_nom=100, marginal_cost=1, carrier="gas")
n.add(
    "StorageUnit",
    "s",
    bus="b",
    p_nom=10,
    max_hours=2,
    carrier="gas",
    state_of_charge_initial=10,
    state_of_charge_initial_per_period=True,
)
n.add(
    "GlobalConstraint",
    "co2",
    type="primary_energy",
    carrier_attribute="co2_emissions",
    sense="<=",
    constant=1e6,
    investment_period=2030,
)
n.optimize(multi_investment_periods=True)
```

A Store with `e_initial=10, e_initial_per_period=True` in place of the StorageUnit raises the same error at line 521.

### Expected Behavior

The model builds. For the stated period, the row counts the emissions of the change in level from `state_of_charge_initial` (or `e_initial`) to the level at the last snapshot of that period, weighted by that period's years, as for a constraint without `investment_period`. The other periods' closing levels do not enter the row.
